# HMP release audit — September 24, 2026

## Verdict: changes and release verification still required

This is an evidence-backed code, regression, browser and read-only production audit, not a guarantee that every historical request is finished or that the apps have no bugs. No production deploy, database migration, client email, or client-data deletion was performed.

Reviewed website branch: `codex/seamless-page-scroll` (starting at `d8b721c`). Reviewed seating branch: `codex/host-client-notes` (starting at `bee0cf6`). Fixes in this audit remain on those change branches. The current live sites are not equivalent to the tested builds.

## Fixed during this audit

- Client messaging CSP blocked local image/PDF previews. Narrowly allow image blob URLs and blob frames, keep same-origin-only scripts and disallow object embeds. A real browser under the amended policy displayed two selected images, removed one with X, and made zero upload/send requests.
- Main message reads silently treated database errors as empty conversations. Return a retryable 502 instead; regression tests cover inquiry and message query failures.
- Replace the old 500-client/2,000-admin message limits with deterministic paged reads for authorized conversations. Tests include 2,001 messages and later-page failures, so newer messages/proposals are not silently omitted by those old limits.
- Hero image decoding could finish an automatic transition after Pause or leaving the hero. Recheck playback state after decoding; regression tests cover delayed decoding.
- Increase message/proposal action text to 12px with 44px minimum targets; verified wrapping and contrast at 390px.
- Seating host responses were persisted wholesale into the shared kiosk offline cache, including internal notes/contact details. Cache only assignment-safe fields; scrub older caches when read, without extending expiry. Unit and browser checks verify internal/client notes and contact details are omitted while VIP tier remains.
- Seating English/Spanish/French default welcome copy now refers to an event. Custom text already saved by organizers is intentionally preserved.
- Updated compatible seating dependency patches: xmldom 0.8.15, postcss-selector-parser 6.1.4 and js-yaml 4.3.2. Full npm audits now report zero known advisories in both repositories.

## Release blockers / remaining follow-up

1. **Five missing migrations**, confirmed against the live migration list: `20260923165336_invoice_event_address.sql`, `20260923234320_client_agreement_forms.sql`, `20260924003341_client_review_requests.sql`, `20260924004440_message_email_notifications.sql`, `20260924005355_sent_document_messages.sql`. Review/apply in dependency order before publishing matching functions/frontend. Do not deploy this branch against the old schema.
2. **Publication approval and production smoke tests** are still needed. Verify an authorized test draft, client links, preview uploads and email delivery to an explicitly approved test recipient. Never test deletions on client data.
3. **Database security maintenance**: Supabase reports outstanding Postgres security patches, disabled leaked-password checks and limited MFA options. Schedule the database upgrade with backup/rollback and review applicable authentication settings. See the security report; no project settings were changed.
4. **Scale follow-up**: message pagination now fixes the old history limits. The admin conversation selector still loads the most recent 500 conversations. Very large installations need paginated conversation selection and on-demand history/signing rather than repeatedly loading every message. This audit did not run a production load test or benchmark that scale.
5. **Performance/accessibility follow-up**: seating has a 503.71 kB minified chunk warning; main Node tests warn about implicit JS module type. Neither fails the build. No blanket WCAG, real-iPhone, slow-network or large-event load certification is claimed.
6. Finish attachment-by-attachment/audio reconciliation and resolve the Money Changing contract wording before stating that every historical request is done.
